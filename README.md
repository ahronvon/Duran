# StoryVerse — Storybook-like Wattpad Website

## How to run
1. Extract `StoryVerse_Complete_Project.zip`.
2. Open the `wattpad_storybook` folder.
3. Double-click `index.html` to open the website in a browser.
4. Internet is only used optionally for Google Fonts; all cover images and story pages are local.

## Included
- `index.html` — home page and 30-book library
- `stories/` — 30 individual story pages, one chapter per book
- `css/style.css` — responsive styling, book cards, reader layout, light/dark themes
- `js/script.js` — search, genre filter, synopsis toggle, likes, details pop-up, reading progress, text-size control, theme toggle
- `js/stories-data.js` — story data used by the details pop-up
- `images/` — 30 locally stored SVG book covers

## Project requirements covered
- 30 storybook covers across different genres
- Each story includes title, author, genre, synopsis, chapter title, story content, and relevant cover image
- Semantic HTML (`header`, `nav`, `main`, `section`, `article`, `footer`)
- One external CSS file and one external JavaScript file
- Working navigation and Read Story links
- Responsive CSS Grid/Flexbox, hover effects, consistent palette, spacing, borders and shadows
- More than two JavaScript features: theme switch, likes, synopsis toggle, details dialog, search/filter, reading progress and font-size control

## Notes
This is a static front-end school project. Likes and theme preference are saved in the current browser using local storage. There is no account system or online database.
